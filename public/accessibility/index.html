Accessibility

Last updated November 2026

We want everyone to be able to use this website. It’s built to meet the Web Content Accessibility Guidelines (WCAG) 2.2, level AA, and we test it with automated checks and keyboard-only browsing.

The map on our Visit page is provided by Google. If it’s hard to use, our address is listed right beside it, along with a link for directions.

If anything on this site is hard to use, please let us know at hello@livencomfort.com, or stop by the shop, and we’ll help and fix it.
